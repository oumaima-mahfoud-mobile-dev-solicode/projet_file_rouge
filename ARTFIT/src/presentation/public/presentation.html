Construire le premier module fonctionnel de la plateforme ARTFIT :

  • CRUD Produits Opérationnel : Création, Lecture, Détail 3D, Modification, Suppression douce (Soft Delete), Recherche et Filtres.

2. Décisions Métier Validées

Toutes les décisions imposées ont été respectées dans le code :

  • Marque Unique ARTFIT (BR-PRD-001) : Tous les produits appartiennent exclusivement à la marque ARTFIT. Aucun vendeur tiers.
  • Devise Unique MAD (BR-PRC-004) : Tous les prix, réductions et paiements sont en Dirham Marocain (MAD) avec 2 décimales.
  • Catégories en Arborescence Infinie (BR-CAT-002) : Hiérarchie sans limite grâce à une clé récursive parent_id.
  • Réservation Panier de 60 Minutes (BR-RES-001) : Le stock est bloqué pendant exactement 60 minutes au moment du panier pour éviter les surventes.
  • Support 3D & Secours 2D (BR-MED-002) : Chaque vêtement 3D (.glb) possède obligatoirement une photo 2D de secours.

3. Modélisation : MCD & MLD

Une structure de données robuste et normalisée en 3e forme normale (3NF) :

MCD (Modèle Conceptuel)

  • 14 entités principales définies.
  • Relation récursive : Catégorie (0,n) ── (0,1) Catégorie.
  • Vêtement (1,1) ── (1,n) Variantes Physiques.
  • Variante (1,1) ── (1,1) Ligne d'Inventaire.
  • Variante (1,1) ── (0,n) Réservations 60 min.

MLD (Modèle Logique)

  • 16 tables relationnelles sécurisées.
  • Clés primaires UUID uniques.
  • Contraintes d'intégrité ON DELETE RESTRICT et CASCADE.
  • Index B-Tree sur les colonnes clés (slug, parent_id, status, deleted_at).

4. Modèle Physique de Données (MPD)

Implémentation SQLite native et script MySQL 8.x prêt à l'emploi :

CREATE TABLE products (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  slug TEXT NOT NULL UNIQUE,
  description TEXT NOT NULL,
  brand_name TEXT NOT NULL DEFAULT 'ARTFIT' CHECK (brand_name = 'ARTFIT'),
  base_price REAL NOT NULL CHECK (base_price > 0.0),
  currency TEXT NOT NULL DEFAULT 'MAD' CHECK (currency = 'MAD'),
  status TEXT NOT NULL DEFAULT 'DRAFT' CHECK (status IN ('DRAFT', 'PUBLISHED', 'ARCHIVED')),
  deleted_at TEXT,
  created_at TEXT NOT NULL DEFAULT (datetime('now'))
);

CREATE TABLE inventory (
  id TEXT PRIMARY KEY,
  variant_id TEXT NOT NULL UNIQUE REFERENCES product_variants(id) ON DELETE CASCADE,
  quantity_on_hand INTEGER NOT NULL DEFAULT 0,
  quantity_reserved INTEGER NOT NULL DEFAULT 0,
  low_stock_threshold INTEGER NOT NULL DEFAULT 5
);

✔ Suppression douce (Soft Delete) garantie via deleted_at.

9. Validation Avant Publication (BR-PRD-003)

Un produit ne peut pas être mis en vente sans respecter ces 5 conditions :

  1. Le titre et la description existent et ne sont pas vides (au moins 3 caractères).
  2. Le produit est rattaché à au moins une catégorie active.
  3. Le prix de base est supérieur à zéro (base_price > 0.00 MAD).
  4. Le produit possède au moins une variante active avec un SKU unique.
  5. Le produit possède au moins une photo principale (is_primary = 1).

✔ Si un élément manque, l'API renvoie une erreur HTTP 400 avec un message clair en français simple.
