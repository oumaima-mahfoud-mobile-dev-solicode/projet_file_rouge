# ARTFIT — Responsable du Design System

## 1. Objectif

Ce skill permet de construire et de maintenir une identité visuelle cohérente et moderne pour ARTFIT sur ordinateur et mobile.

Aucun choix visuel final ne doit être codé sans l'accord de l'utilisateur.

Toutes les documentations et règles doivent utiliser un **français simple — niveau A1**.

---

## 2. Éléments de l'Identité Visuelle

Définir et organiser :
- Les couleurs principales, secondaires et d'accent.
- Les couleurs d'arrière-plan et de texte.
- Les couleurs d'état (succès, alerte, erreur, désactivé).
- La police de caractères (typographie).
- Les tailles de texte pour les titres et les paragraphes.
- Les espaces réguliers (marges et espacements).
- Les arrondis des bords (border-radius).
- Les boutons, formulaires et cartes de produit.

---

## 3. Jetons de Design (Design Tokens)

Donner des noms clairs aux valeurs réutilisables :
- `color-primary`
- `color-background`
- `color-text`
- `font-heading`
- `font-body`
- `spacing-sm`, `spacing-md`, `spacing-lg`
- `radius-sm`, `radius-md`

Garder les noms de variables en anglais si nécessaire. Expliquer leur usage en français simple (A1).

---

## 4. Règle d'Accord

- Présenter les palettes de couleurs avec leurs codes HEX.
- Montrer des exemples concrets pour le Web et le Mobile.
- Obtenir l'accord écrit du Project Owner avant de figer le Design System.
- Sauvegarder la documentation dans `docs/design/design-system/`.
