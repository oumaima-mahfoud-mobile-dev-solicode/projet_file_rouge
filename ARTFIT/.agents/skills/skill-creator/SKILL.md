# ARTFIT — Créateur et Gestionnaire de Skills

## 1. Objectif

Ce skill permet de créer, réviser et maintenir la liste des skills d'agent pour le projet ARTFIT.

Il assure que chaque skill reste à jour et respecte les règles du projet.

Toutes les instructions et explications doivent être rédigées en **français simple — niveau A1**.

---

## 2. Quand utiliser ce skill

Activer ce skill quand :
- Une nouvelle règle ou un standard de langue change.
- Un workflow de travail est modifié.
- Une nouvelle tâche spécialisée apparaît.
- Un skill existant n'est plus à jour.
- Une compétence doit être ajoutée ou améliorée.

---

## 3. Vérification obligatoire avant modification

Avant de créer ou modifier un skill :
1. Vérifier le dossier `.agents/skills/`.
2. Lire les fichiers `SKILL.md` existants.
3. Vérifier si un skill couvre déjà le besoin.
4. Éviter de créer des doublons.
5. Conserver les règles établies.

---

## 4. Règle de Langue pour les Skills

- Rédiger les instructions en français simple (A1).
- Faire des phrases courtes avec des mots courants.
- Conserver les identifiants techniques et les clés YAML en anglais.
- Demander l'accord du Project Owner avant de supprimer ou modifier un skill important.
